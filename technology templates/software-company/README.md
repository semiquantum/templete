# Apex DevForge — Elite Software & Systems Engineering Template

A technical, high-precision engineering website template built for custom software development agencies, cloud-native engineering firms, distributed systems teams, and DevOps consultancies.

## Key Features

- **Technical Engineering Aesthetic**: Clean graphite dark modes, steel blue accents, terminal mint highlights, and syntax-highlighted code blueprints.
- **Full Architecture Showcase**: Go/Rust distributed microservices, TypeScript web platforms, legacy monolith modernization, and automated GitOps CI/CD pipelines.
- **Engineering Squad Engagement Tiers**: Predictable weekly sprint models with explicit deliverables.
- **Comprehensive Sections**:
  1. Top Engineering Meta Strip
  2. Sticky Navigation Bar with Squad Assembly CTA
  3. Hero Section with Live Syntax-Highlighted Code Blueprint Card
  4. Core Engineering Philosophy & Quality Pillars
  5. Full-Lifecycle Engineering Services Grid
  6. Dark-Mode Quality Standards & SRE Guardrails
  7. Technology Arsenal Stack (Go, Rust, TypeScript, Kafka, Kubernetes)
  8. Engineering Statistics & Uptime Banner (240+ releases, 98% coverage)
  9. Distributed Systems Case Studies (Fintech, Telemetry, Healthcare)
  10. 4-Phase Delivery Process Workflow
  11. Developer Toolchain Integrations (GitHub, Docker, Terraform, Prometheus)
  12. Engagement Pricing Tiers (Sprint Prototype, Dedicated Squad, Re-Architecture)
  13. Engineering Executive Client Testimonials
  14. Accessible FAQ Accordion
  15. Mission-Critical Software CTA Wrap
  16. Squad Assembly Request Form with Real-Time Validation
  17. Multi-Column Footer with Runtime Badges

## Customization Guide

### CSS Custom Variables (`style.css`)
```css
:root {
  --cyan: #0EA5E9;          /* Steel Blue Accent */
  --cyan-hover: #0284C7;
  --bg-main: #FFFFFF;
  --bg-dark: #0B0F17;       /* Deep Graphite */
  --text-main: #0F172A;
}
```

### Running the Template
Open `index.html` in any web browser. Zero frameworks or dependencies needed.
