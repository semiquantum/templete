# CoreMatrix IT Solutions — Enterprise IT Website Template

A modern, responsive, and client-ready frontend website template designed specifically for enterprise technology providers, IT consulting firms, cloud infrastructure specialists, and digital transformation agencies.

## Features Included

- **Semantic HTML5 & Modern CSS3**: Zero CSS frameworks (no Tailwind, no Bootstrap), built with modular CSS custom properties (variables).
- **Zero-Dependency Vanilla JavaScript (ES6)**: Clean, lightweight interactions with zero external script dependencies.
- **Enterprise Sections**:
  1. Top Technology Strip & Global Meta Bar
  2. Sticky Navigation with Mobile Drawer & Escape Key Support
  3. High-Impact Hero with Live CSS Server Telemetry Terminal
  4. Technology Introduction & Core Capability Highlights
  5. Core Services Grid with Deep-Dive Features
  6. Zero-Trust Security & Disaster Recovery Solutions (Dark Theme)
  7. Certified Enterprise Technology Stack Grid
  8. Quantifiable Statistics & SLA Metrics Banner
  9. Enterprise Transformation Case Studies
  10. Ecosystem Integrations Showcase
  11. Executive Testimonials & Client Endorsements
  12. Transparent Engagement Pricing Tiers
  13. Accessible Interactive FAQ Accordion
  14. High-Conversion CTA Banner
  15. Complete Contact Section with Interactive Form Validation
  16. Comprehensive Footer with Compliance Badges & Navigation

## Customization Guide

### Color Tokens (in `style.css`)
```css
:root {
  --bg-main: #FDFCFB;
  --bg-tint: #F4EFEA;
  --bg-dark: #121417;
  --text-primary: #181A1F;
  --accent: #D96B27;        /* Brand copper/orange accent */
  --accent-hover: #C05A1A;
}
```

### Running Locally
Simply open `index.html` in any modern web browser or serve via any static HTTP server (e.g. `npx serve .` or VS Code Live Server).
