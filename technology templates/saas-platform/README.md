# FlowPilot — Modern B2B SaaS Website Template

A high-conversion, product-led frontend website template crafted for modern B2B SaaS platforms, developer observability tools, cloud automation products, and API platforms.

## Key Features

- **Product-Led Design**: Live-rendered interactive CSS dashboard preview with animated telemetry bars and real-time status telemetry.
- **Interactive Pricing Switcher**: Dynamic Monthly / Annual billing toggle with real-time price updates (Save 20%).
- **Interactive Workflows**: Step-by-step pipeline visualization and distributed architecture cards.
- **Zero-Dependency Vanilla JavaScript (ES6)**: Accessible drawer navigation, smooth scroll, FAQ accordion, and real-time form validation.
- **Complete Suite of Sections**:
  1. Top SaaS Notification Banner
  2. Sticky Navigation Bar with Trial CTA
  3. Product-Centric Hero with Dashboard UI Preview
  4. Enterprise Customer Social Proof Logos
  5. Architecture & Product Introduction (Sub-ms ingestion, runbooks, graph)
  6. Core Feature Cards with Performance Metrics
  7. 3-Step Automated Resolution Workflow
  8. OpenTelemetry & Cloud Stack Overview
  9. Scale & Reliability Statistics Banner
  10. DevOps Ecosystem Integrations (Slack, GitHub, Datadog, Jira)
  11. Developer Testimonials Deck
  12. Interactive Pricing Tier Cards (Starter, Growth Pro, Enterprise)
  13. Accessible FAQ Accordion
  14. High-Conversion CTA Banner
  15. Trial Registration & Demo Contact Form with Validation
  16. Multi-Column Footer with Real-Time SLA Indicator

## Customization Guide

### CSS Custom Variables (`style.css`)
```css
:root {
  --primary: #4F46E5;       /* Electric Indigo */
  --primary-hover: #4338CA;
  --bg-main: #FFFFFF;
  --bg-alt: #F8FAFC;
  --text-main: #0F172A;     /* Deep Slate Navy */
}
```

### Running the Template
Open `index.html` in any web browser. No compilation, npm, or build step required.
