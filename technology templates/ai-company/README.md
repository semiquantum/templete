# Nexa Intelligence — Autonomous Cognitive Systems Template

A sophisticated, editorial, and research-driven technology website template designed for enterprise AI foundation model companies, deep-tech research labs, and cognitive agent infrastructure providers.

## Key Highlights

- **Research-Grade AI Aesthetic**: Avoids neon glow blobs and kitschy gradients; utilizes an obsidian, crisp platinum, and restrained violet/amethyst palette.
- **Simulated Inference Preview**: Interactive AI Reasoning Graph with vector retrieval telemetry, multi-step chain-of-thought, and autonomous action execution.
- **Enterprise Sections**:
  1. Top Research Benchmark Announcement Strip
  2. Elegant Sticky Navigation with Sovereign Model CTA
  3. Hero Section with Live Agentic Reasoning Trace
  4. Foundation Models Showcase (Nexa-Core 70B, Nexa-Embed 3072, Nexa-Agents SRE)
  5. The Four Pillars of Sovereign AI Architecture
  6. Mission-Critical Industry Capabilities (Finance, Healthcare, Legal, Engineering)
  7. High-Throughput Inference & Acceleration Stack (TensorRT-LLM, vLLM, Qdrant)
  8. Research & Benchmark Metrics Banner (MMLU-Pro 94.2%, 128K context)
  9. Enterprise Ecosystem & Warehouse Connectors (Snowflake, Databricks, BigQuery)
  10. Transparent API & On-Premises Token Economics Tiers
  11. Research Scientist Testimonials & Endorsements
  12. Accessible FAQ Accordion
  13. Sovereign Deployment CTA Card
  14. Comprehensive Model Evaluation Request Form with Validation
  15. Multi-Column Footer with Governance & Privacy Links

## Customization Guide

### CSS Custom Variables (`style.css`)
```css
:root {
  --bg-deep: #080A0F;
  --bg-surface: #141924;
  --violet: #8B5CF6;          /* Restrained Purple Accent */
  --text-main: #F3F4F6;
}
```

### Running the Template
Open `index.html` in any web browser. Zero frameworks, npm dependencies, or build tools required.
