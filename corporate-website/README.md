# Corporate Website Template

## Overview

A professional, responsive corporate website template built with HTML5,
CSS3, and vanilla JavaScript. The template is designed for companies
that want a clean business website with a modern, trustworthy visual
style.

## Design Theme

The current UI uses the following color palette:

-   **Ivory** --- primary page and section backgrounds
-   **Charcoal** --- headings, navigation, dark panels, and footer
    elements
-   **Terracotta** --- primary buttons, highlights, charts, and calls to
    action
-   **Sage Green** --- secondary accents, supporting UI elements, and
    visual highlights

The previous pink color treatment has been removed from the main visual
assets.

## How to Run

1.  Extract the ZIP file.
2.  Open the `corporate-website` folder.
3.  Open `index.html` in a modern web browser.

For development, you can also use a local server such as VS Code Live
Server.

## Customization

### Change Company Content

Edit the text and section content directly in:

`index.html`

### Change Colors

The main theme colors are defined in:

`css/style.css`

Search for the existing color variables or theme color declarations and
update them consistently.

### Change Team Images

Replace the images inside:

`images/`

Keep the same filenames if you want to avoid changing the image paths in
the HTML.

### Update JavaScript Behavior

Frontend interactions can be modified in:

`js/script.js`
