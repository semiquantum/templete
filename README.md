# Business Frontend Template Collection

A collection of five independent, client-ready business website templates.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- No frameworks
- No external runtime dependencies
- No build step required

## Templates
- Business Consulting
- Business Agency
- Startup Company
- Professional Services
- Corporate Business

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Publish
Each template folder is independently publishable. Upload the contents of the selected folder to any static hosting provider.

## Download
The `downloads/` directory contains a ZIP package for each individual template so a user can download a standalone template.

## Performance approach
- No JavaScript framework
- No external libraries
- No external font dependency
- No image dependency
- Minimal DOM interaction
- IntersectionObserver used only for reveal animations
- Reduced-motion support
- Responsive CSS
- Native HTML form controls
- No backend/network calls

## Important
The contact form is a frontend demo. It validates and displays success/error states but does not send email without a backend/form service.
