# Frontend Website Templates — Day 1 & Day 2

A collection of professional, modern and responsive frontend website templates developed as part of the two-day frontend template assignment.

The project contains **10 independent website templates**:

- 5 Business templates — Day 1
- 5 Technology templates — Day 2

All templates are developed using HTML5, CSS3 and Vanilla JavaScript (ES6).

---

## Project Overview

The purpose of this project is to create client-ready frontend website templates demonstrating:

- Professional UI/UX
- Modern layouts
- Responsive design
- Reusable frontend components
- Interactive JavaScript elements
- Smooth animations
- Accessible interaction states
- Mobile, tablet and desktop compatibility

Each template has its own visual identity and can be used independently as a starting point for a client website.

# UI/UX Principles

The templates are designed to provide:

- Professional visual hierarchy
- Consistent spacing
- Clear navigation
- Meaningful content structure
- Responsive layouts
- Accessible interaction states
- Clear calls to action
- Industry-appropriate visual identity
- Client-ready presentation

The templates are intentionally designed with different visual identities rather than using the same layout repeatedly.

---

# Responsive Design

Templates are designed for:

- Mobile phones
- Tablets
- Laptops
- Desktop screens
- Large desktop displays

Responsive implementation uses:

- CSS Grid
- Flexbox
- Media queries
- Fluid sizing
- Responsive typography
- Flexible containers

The layouts are intended to prevent:

- Horizontal overflow
- Content clipping
- Overlapping sections
- Broken navigation
- Broken cards
- Form overflow
- Footer overflow

---

# Accessibility

Where applicable, the templates include:

- Semantic HTML
- Keyboard-friendly navigation
- Visible focus states
- Accessible mobile navigation
- Form labels
- ARIA states
- Reduced-motion support
- Accessible interactive components

---

# Interactive Features

Depending on the template, frontend JavaScript is used for:

- Mobile navigation
- FAQ interactions
- Form validation
- Interactive UI components
- Scroll animations
- Navigation behavior

All functionality is frontend-only.

Forms provide frontend validation and UI feedback; they do not send real emails without a backend service.

---

# Running the Templates

No build process is required.

Open the individual template's `index.html` in a modern browser.

Example:

```text
templates/it-company/index.html
```

or:

```text
templates/business-consulting/index.html
```

The root project/showcase page can be used to access the available templates where applicable.
