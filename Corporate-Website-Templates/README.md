## 🚀 Getting Started

No compilation or build step required! All templates use **pure standard HTML5, CSS3, and Vanilla JavaScript (ES6)** with inline SVG graphics for 100% offline reliability.

### Running Locally

1. Open the root `index.html` file in any modern web browser.
2. Alternatively, start a simple HTTP server using Python:
   ```bash
   python -m http.server 8000
   ```
3. Navigate to `http://localhost:8000` to launch the **Master Showcase Hub**.

## 📱 Responsive & Interactive Features

- **Responsive Drawers**: Hamburger menus on tablet & mobile viewports.
- **Form Validation**: Live validation UI with custom feedback modals across contact forms.
- **Pure Vanilla JS**: Zero dependencies on heavy frameworks like jQuery, Bootstrap, or Tailwind.
- **High Performance**: Clean CSS architecture utilizing CSS Variables, Flexbox, and CSS Grid.
