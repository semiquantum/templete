Frontend Engineering

Pure Vanilla Web Technologies

Engineered for blazing fast speed, complete cross-browser compatibility, and zero dependency friction.

1. Modular CSS Architecture

Organized into shared tokens (global.css), reusable components (components.css), smooth keyframes (animations.css), and robust responsive queries (responsive.css).

2. ES6 State & Storage

Persistent wishlist favorites, side-by-side comparison arrays, and modal gallery state all managed via modern ES6 arrow functions, array methods, and safe localStorage.

3. Multi-Device Verified

Tested across 320px, 375px, 390px, 414px, 768px, 1024px, 1280px, and 1440px+ displays with zero horizontal overflow and seamless mobile navigation drawers.
